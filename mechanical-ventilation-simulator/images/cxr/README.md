# Chest radiograph images

Put image files here and register them in `../../cxr-images.js`, which is where
the licence and source URL for each one live. An image without those fields is
not displayed — the module falls back to its drawn schematic rather than show a
picture uncredited.

See the header of `cxr-images.js` for sources that are actually reusable
(Wikimedia Commons, NIH ChestX-ray14, Open-i, PMC open-access, CDC PHIL) and
the ones to avoid bundling (Radiopaedia, LITFL, MIMIC-CXR, CheXpert).
